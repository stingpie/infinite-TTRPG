This is an old project of mine. You need either the openAI API, or the anthropic API, along with the corresponding key. 

Once you have that set up, you can run the program with this command:

>python test.py 
   
If you instead want to narrate an adventure instead of play in one, type 

>python test.py -n
   
To include a specific character from the player_character directory, 

>python test.py -c [PUT THE CHARACTER NAMES HERE]

You can add more lore to the world by adding files to lore/common, lore/simple-setting, or create your own setting: lore/[NAME OF YOUR SETTING HERE]/[PUT YOUR FILES HERE]
